# 60-second demo script

**Setup:** `cd web && npm run dev`. Open http://localhost:5173 in a window at least 1024 px wide (the room controls sit on the 3D view only at that width). Clear site data first, so the app opens in simple mode and the alignment banner shows (`sv.uiMode` is remembered in `localStorage`). With site data cleared the theme follows the system (`sv.theme`). No API or key is needed: the examples replay recorded inference.

Control labels below are taken from the components: `Landing.tsx`, `landing/ExampleStage.tsx`, `SunReport.tsx`, `twin/RoomControls.tsx`, `TwinView.tsx`, `Timeline.tsx`, `photo/AlignCheck.tsx`, `photo/ViewStrip.tsx` and `kit.tsx` (`ModeSwitch`, `ThemeToggle`).

**Fallback lines if asked:**

* *"Is any of this made up?"* Every value carries a provenance tag (observed, inferred, map, assumed or manual). Buildings outside the photos are never labelled as reconstructed from them. When a photo has no focal length, the FOV is inferred from a 3.3 m storey and the note says so.
* *"How accurate is it?"* Amsterdam: +0.32 m against the 3D BAG lidar 70th-percentile roof (−3.02 m against the ridge, which is cropped out of the photo). Paris: −0.38 m against IGN BD TOPO, whose stated precision is ±2.5 m. New York: −0.09 m against OSM after auto-alignment, versus +7.5 m with the hand-picked camera. Three buildings are not a benchmark; the numbers and caveats are in `docs/VALIDATION.md`.
* *"Does it work on a phone? In daylight?"* On a phone the workspace is one scrolling column, answer first, with the day bar docked at the bottom (one finger scrolls, two fingers orbit the 3D view). There the *System / Light / Dark* toggle is in the top bar's ⋯ (More) menu, under Theme; *System* follows the device.
* *"Why does the key go through your server?"* Roboflow serverless doesn't send CORS headers to other origins, so the browser can't call it. Your key stays in your browser's session storage (localStorage only if you tick *Remember on this device*) and travels to our API only in an `X-Roboflow-Key` header, which our API never logs or stores. The optional *Check key* sends it directly to `api.roboflow.com`.
